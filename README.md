# Base Eleitoral — Mauriti 2026

Sistema web estático para consulta da votação por candidato, local de votação e seção.

## Publicação no GitHub Pages

1. Envie `index.html` e `.nojekyll` para a raiz do repositório.
2. Vá em **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/ (root)`.
5. Salve e aguarde a publicação.

O sistema não depende de servidor, banco de dados ou instalação de programas.
